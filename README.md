# fahadjibransheikh/homebrew-tap

Homebrew tap for Fahad Sheikh's Mac apps. The apps' DMGs are attached to this repo's releases.

```bash
brew install --cask fahadjibransheikh/tap/mynah
brew install --cask fahadjibransheikh/tap/raven
```

| Cask | What it is |
|------|------------|
| mynah | Bot-free meeting notes: records calls, transcribes locally, names who spoke |
| [raven](https://github.com/fahadjibransheikh/raven) | Desktop email client (downloads from Raven's own releases, which its in-app updater reads) |
