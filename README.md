# Flock

Flock is Fahad Sheikh's collection of bird-named apps, and this repo is its Homebrew tap (`fahadjibransheikh/flock`). The apps' downloads are attached to this repo's releases.

```bash
brew install --cask fahadjibransheikh/flock/mynah
brew install --cask fahadjibransheikh/flock/peregrine
brew install --cask fahadjibransheikh/flock/raven
```

| Cask | What it is |
|------|------------|
| mynah | Bot-free meeting notes: records calls, transcribes locally, names who spoke |
| peregrine | Casts your Mac's screen and sound to a TV from the menu bar |
| raven | Local-first desktop email client with calendar and contacts. Its in-app updater reads `updates/raven.json` here |
